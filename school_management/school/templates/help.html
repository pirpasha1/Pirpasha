❓ How to use this system

Simple step-by-step guide for school staff. No technical knowledge needed.

1. First-time setup (Administrator)

  1. Open School Settings → type the school name, address, academic year, session dates → Save.
  2. Open Subjects and check the list. Add or rename subjects if needed.
  3. Open Teachers → Add Teacher for every staff member.
  4. Open Classes → type the class (e.g. 6) and sections (e.g. A, B) → Create. Then click a class to choose its class teacher and subject teachers.
  5. Open User Logins to give each teacher their own username and password.

2. Admitting students

  • One student: New Admission → fill the form → Save. The admission number is filled in automatically.
  • Many students: Import from Excel → download the template → fill it in Excel → upload it.
  • To correct details, open the student and click Edit.
  • At the end of the year use Promote / Transfer to move a whole class up, or mark students as Left / TC issued.

3. Daily attendance

  1. Click Mark Attendance and choose the class.
  2. Everyone is Present (P) by default. Click A for absent or L for leave.
  3. Click Save Attendance. You can open the same date again to correct mistakes.
  4. See the full month in Monthly Register and download it as PDF or Excel.

4. Exams, marks and report cards

  1. Exams: create each exam once (e.g. Periodic Test 1, max marks 40).
  2. Enter Marks: choose exam → class → subject. Type the marks; press Enter to jump to the next student. Type AB for absent. Click Save & next subject.
  3. Mark Sheet shows totals, percentage, grade and rank for the whole class.
  4. Teacher Remarks: write a remark for each student (or pick a ready-made one).
  5. Report Cards: choose the class → print one report card or download all as a single PDF.

5. NCERT chapters & learning outcomes

  1. NCERT Chapters: add the chapters of each textbook (or import them from Excel), with the learning outcomes.
  2. Chapter Progress: for each class, mark chapters as In Progress or Completed with dates.
  3. Learning Outcomes: list the competencies to track for each class and subject, linked to chapters.
  4. Assess Competencies: for each student choose a level: 1 Beginning, 2 Developing, 3 Proficient, 4 Advanced.
  5. Grade Indicators: give A / B / C / D grades for Work Education, Art, Health & PE, Discipline and life skills.

6. Printing & downloads

  • Every list has ⬇ PDF, ⬇ Excel and 🖨 Print buttons.
  • Reports & Downloads collects all reports in one place.
  • PDF files open in any browser or PDF reader and print neatly on A4 paper.
  • Excel files can be opened in Microsoft Excel, LibreOffice or Google Sheets.

7. Keeping data safe

  • Administrator: go to School Settings → Download Backup at least once a week and keep the file on a pen drive.
  • If the computer fails, install the system again and use Restore Backup.
  • Never share the admin password. Give each teacher their own login.
